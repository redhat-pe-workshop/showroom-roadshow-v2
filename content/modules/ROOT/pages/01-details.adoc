== Timing

The workshop is split into multiple modules that can be completed in an order of your choosing. Following the modules in order is recommended for the best experience. You won't be writing code or hand-crafting YAML -- you'll mostly be deploying existing configurations to observe the benefits that thoughful platform engineering provides.

== How you'll work

You will use a GitOps-driven configuration approach. This means you'll use OpenShift GitOps to deploy and manage platform components. Don't worry if this is new to you -- it'll be explained as you follow the content. It essentially boils down to a set of YAML files in a Git repository being continuously reconciled against your OpenShift cluster. We're taking a production-like approach in this workshop! 😎

=== Executable terminal commands

Throughout the workshop, you'll see command snippets with a terminal icon in the top-right corner. Select the terminal tab on the right, then click terminal icon in the snippet to automatically execute the command in the Wetty terminal tab. 

Try it now. Select the **Terminal** tab, then click the icon in snippet below:

[source,bash,role="execute"]
----
oc version --client
----

This should display your OpenShift CLI version. You can also copy commands and paste them manually, but the play button makes it faster!
