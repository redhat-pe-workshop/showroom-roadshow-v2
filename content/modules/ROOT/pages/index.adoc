= Platform Engineering Workshop

Welcome to the Platform Engineering Workshop!

== Your role and mission

You're a platform engineer at Parasol Insurance. Your development teams are growing but onboarding is slow, environments are inconsistent, and developers spend too much time filing tickets instead of shipping features. Meanwhile, the security team is struggling to enforce supply chain compliance -- there's no consistent way to scan dependencies, sign artifacts, or verify provenance across teams.

Your CTO has tasked you with building an Internal Developer Platform (IDP) that eliminates these bottlenecks. The platform should make the secure path the easy path -- developers get self-service access to golden-path templates, pre-configured CI/CD pipelines, and a unified portal where they can discover services, APIs, and documentation without filing a ticket.

== What you'll learn

* How the Red Hat Developer Hub operator works
* Deploy workloads using GitOps
* Configure Developer Hub with essential integrations via dynamic plugins
* SSO integration with Keycloak
* Integrate CI/CD providers with Developer Hub
* Register entities in the software catalog
* Enable developer self-service using software templates
* Add AI-powered assistance with Lightspeed and MCP

== What you'll build

You'll progressively build Parasol's IDP using a GitOps-driven approach:

. **Explore the application platform** -- See the OpenShift capabilities that form the foundation
. **Deploy Developer Hub** -- Use Argo CD to deploy a minimal instance from a Backstage custom resource
. **Configure SSO and plugins** -- Add authentication, CI/CD visibility, and topology plugins
. **Populate the software catalog** -- Register Parasol's services and APIs
. **Enable self-service templates** -- Import golden-path templates for application creation
. **Add AI assistance** -- Enable Lightspeed with MCP for catalog-aware AI

Each step builds on the previous one. You'll advance through configurations using Argo CD -- no hand-crafted YAML required.

== Who this is for

This workshop is designed for platform engineers and DevOps leads with intermediate to advanced experience with OpenShift and Kubernetes.

== Prerequisites

* Familiarity with OpenShift and Kubernetes concepts
* Basic understanding of Git and YAML
* Experience with CLI tooling (`oc`, `git`)
