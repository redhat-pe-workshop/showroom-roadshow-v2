== Service accounts

=== Vault

Vault uses token authentication. Retrieve the root token with:

[source,bash,role="copypaste",subs="attributes+"]
----
oc get secret vault-token -n vault -o jsonpath='{.data.token}' | base64 -d && echo
----

=== Keycloak

Keycloak admin credentials are stored in a Secret on the cluster. Retrieve them with:

[source,bash,role="copypaste",subs="attributes+"]
----
oc get secret keycloak-initial-admin -n keycloak -o jsonpath='{.data.username}' | base64 -d && echo
oc get secret keycloak-initial-admin -n keycloak -o jsonpath='{.data.password}' | base64 -d && echo
----
